# Wii 스타일 캐릭터 6종 - 텍스처 버전

얼굴·몸 디테일을 추가 지오메트리(타원체/튜브 조각)로 붙이지 않고, UV가 있는 깔끔한 메쉬에
**이미지(baseColorTexture)로 그려서 입혔습니다.**

- 얼굴: 머리 메쉬(UV 구체) + 1024x1024 얼굴 텍스처 (눈/하이라이트/눈썹/코/볼터치/입/속눈썹/안경/콧수염 전부 그림)
- 사복: 셔츠/드레스/치마/바지/양말/신발 텍스처 (별, 줄무늬, 단추, 칼라, 물방울, 주름, 벨트 등)
- 과잠: 몸통 2048x512 + 소매 512x512 텍스처 (립 줄무늬, 스냅 단추, 포켓선, 엠블럼, 등 프린트, 왼소매 26, 오른소매 H 뱃지)
- 머리카락, 귀, 손만 단색 모양입니다.

파일: `<id>_outfits.glb`(사복+과잠 둘 다), `_casual.glb`, `_jacket.glb`, `lineup_*.glb`
노드 이름/토글 방식은 이전과 동일: `<id>_Body|ArmL|ArmR _Outfit_Casual / _Outfit_Jacket` 의 `.visible` 전환.

텍스처 교체: `source/paint_body.py`(옷), `source/facepaint.py`(얼굴) 수정 후
`python3 make_tex.py out_dir` (모바일 경량 `--lite` = 텍스처 절반 해상도).
과잠 시안 이미지는 스타장닷컴 저작물(비영리 사용)이므로 학술제 등 비영리 용도로만 사용하세요.
